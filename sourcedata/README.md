# sourcedata

Original release files of the source dataset, as far as they can be redistributed.

## Release files stored under their release names (added 2026-10-11)

20 release files of Zenodo record 10808054 (https://doi.org/10.5281/zenodo.10808054) are listed under `sourcedata/zenodo-10808054/` with their release paths.
They take no extra storage: each is a git-annex pointer to the same content as the BIDS file named in
`sourcedata/SOURCEDATA_POINTERS.tsv`.

All 20 are byte for byte the released files. The feature CSVs are byte-identical to the BIDS `*_features.csv` files (`checksums.tsv` gives the Zenodo MD5s).
